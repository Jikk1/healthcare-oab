# 0001 — Vite + Vanilla JS без UI-фреймворка

- Статус: Accepted
- Дата: 2026-06

## Контекст

Фронтенд начинался как набор статических HTML/CSS/JS без сборки (папка `vendor/`,
глобальные скрипты). Нужны были npm-зависимости (Chart.js, Lenis), env-переменные,
code-splitting и хэширование ассетов — но без тяжёлого рантайма фреймворка: страницы
преимущественно контентные (лендинг, научные страницы) плюс несколько интерактивных
инструментов, а команда небольшая.

## Решение

Собираем многостраничное приложение на **Vite** (Rollup под капотом), рантайм — на
**Vanilla ES-модулях**. Каждая HTML-страница — отдельная точка входа
(`vite.config.js`), общие модули Vite выносит в общие чанки. Никакого React/Vue.

## Последствия

- **+** Малый рантайм, быстрый TTI, простой ментальный модель; DOM-логика явная.
- **+** Полноценная сборка: `import` npm-пакетов, `import.meta.env`, hashed-ассеты, HMR в dev.
- **−** Нет реактивности из коробки — состояние и обновления DOM пишем руками
  (делегирование событий, ручной рендер innerHTML). Для сложного stateful-UI
  (будущий развитый дашборд) это может стать узким местом — тогда точечно вводим
  веб-компоненты или островки фреймворка, не переписывая всё.
- Тесты — Vitest (jsdom); IIFE-модули импортируются и проверяются через `window.*`.
