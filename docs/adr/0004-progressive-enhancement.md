# 0004 — Прогрессивное улучшение (демо → живые данные)

- Статус: Accepted
- Дата: 2026-06

## Контекст

Публичные страницы-инструменты (OmniRisk, «Анализы», демо Кокса) должны работать без
бэкенда — для маркетинга, офлайн-показа и быстрой оценки. При этом врач с сессией
должен видеть живые данные из API. Нужен единый код без жёсткой зависимости от сервера.

## Решение

Каждая страница — самодостаточное **демо по умолчанию**: расчёты выполняет браузерный
движок (`omnirisk.js`, снапшот `cox-demo.json`), данные синтетические. Наличие сессии
— это **улучшение, а не гейт**: `ensureSession()` тихо пробует refresh; при успехе
дашборд/страницы подтягивают живые данные из API и переключаются в serverMode. При
недоступности сервера или отсутствии сессии остаётся рабочее демо.

## Последствия

- **+** Ценность без бэкенда (SEO, демо, отказоустойчивость); один код для demo и live.
- **+** Мягкая деградация: сеть/сервер недоступны → плейсхолдеры и демо-данные, без белого экрана.
- **−** Двойные пути (клиентский расчёт vs серверный) нужно держать согласованными;
  часть чисел в демо иллюстративна и помечена как таковая.
