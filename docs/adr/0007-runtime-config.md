# 0007 — Рантайм-конфиг из окружения (один иммутабельный образ)

- Статус: Accepted
- Дата: 2026-06

## Контекст

Один и тот же собранный фронтенд-образ должен разворачиваться в разных средах (dev/
stage/prod) с разным адресом API — без пересборки на каждый деплой. Vite-бандл
статичен, значит адрес API нельзя «зашивать» на этапе build.

## Решение

Адрес API читается в рантайме из `window.HC_CONFIG.apiBase`. Файл `/config.js`
**не бандлится** (лежит в `public/`), а перегенерируется при старте контейнера
`docker-entrypoint.sh` из переменной `$API_BASE`. Из того же `$API_BASE` энтрипойнт
выводит `connect-src` для CSP ([ADR-0005](0005-strict-csp.md)) и рендерит
`security-headers.conf` из шаблона. nginx отдаёт `/config.js` с `no-store`.

Приоритет источников в `api.js`: `HC_CONFIG.apiBase` → `import.meta.env.VITE_API_BASE`
→ `<meta name="hc-api-base">` → localhost-дефолт.

## Последствия

- **+** Один образ на все среды; смена окружения = смена env, без пересборки.
- **+** CSP `connect-src` и адрес API согласованы (общий источник — `$API_BASE`).
- **−** Есть блокирующий `/config.js` до `api.js`; кэш отключён (`no-store`) — цена мала.
